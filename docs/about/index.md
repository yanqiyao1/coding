我是严棋耀（Qiyao Yan），北京大学在读。

平时主要做两件事：一是系统和编译器方向的学习与课程项目，写 C/C++、读汇编、拿 gdb 和 perf 当日常工具；二是在组里做 LLM 推理与可解释性相关的研究。这个博客只记第一类，也就是那些「代码层面能讲清楚」的东西。

## 这里写什么

- **C / C++**：对象模型、未定义行为、编译器的优化逻辑
- **系统**：进程与线程、虚拟内存、链接、调试与性能测量
- **工具**：编译器选项、CMake、Git、Shell
- **算法**：以「为什么这样写更慢」为主，而不是刷题题解

不写的内容：框架速成、AI 生成的清单文、没有跑过的性能数字。

## 一些约定

文章里的代码都是在 `-Wall -Wextra` 下编译通过、并且真正跑过的。涉及到平台差异时会注明是 Linux/aarch64 还是 macOS/arm64。

性能数字都是在自己机器上测的，会写清楚编译选项和数据规模——数字的意义在于数量级和趋势，不在于精确到小数点后两位。
